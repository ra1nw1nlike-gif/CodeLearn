> Веб-платформа для проведення онлайн-курсу з програмування з інтерактивними завданнями та автоматизованою перевіркою розв’язків.

##  Загальна інформація

* **Тип проєкту**: Веб-платформа для онлайн-навчання
* **Мова програмування**: JavaScript
* **Frontend**: React.js
* **Backend**: Node.js, Express.js
* **База даних**: MongoDB

## ▶ Як запустити проєкт "з нуля"

### 1. Встановлення інструментів

Перед запуском проєкту потрібно встановити:

* Node.js
* npm
* MongoDB або використати MongoDB Atlas
* Git

---

### 2. Клонування репозиторію

```bash
git clone [https://github.com/ra1nw1nlike-gif/CodeLearn.git]
cd [назва папки проєкту]
```

---

### 3. Встановлення залежностей

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd frontend
npm install
```

---

### 4. Створення `.env` файлу

У папці `backend` потрібно створити файл `.env` та додати основні змінні середовища:

```env
PORT=5000
MONGO_URI=mongodb://localhost:27017/codelearn
JWT_SECRET=secret_key
JUDGE0_API_URL=https://judge0-ce.p.rapidapi.com
JUDGE0_API_KEY=your_api_key
```

Якщо використовується MongoDB Atlas, у полі `MONGO_URI` потрібно вказати посилання на хмарну базу даних.

---

### 5. Запуск серверної частини

```bash
cd backend
npm start
```

Після запуску серверна частина буде доступна за адресою:

```text
http://localhost:5000
```

---

### 6. Запуск клієнтської частини

```bash
cd frontend
npm run dev
```

Після запуску клієнтська частина буде доступна у браузері за адресою, яку виведе термінал, наприклад:

```text
http://localhost:5173
```

##  API приклади

###  Реєстрація користувача

**POST /api/auth/register**

```json
{
  "name": "Andrii",
  "email": "user@example.com",
  "password": "123456"
}
```

**Response:**

```json
{
  "message": "Користувача успішно зареєстровано"
}
```

---

###  Авторизація користувача

**POST /api/auth/login**

```json
{
  "email": "user@example.com",
  "password": "123456"
}
```

**Response:**

```json
{
  "token": "jwt_token_here",
  "user": {
    "id": "user_id",
    "name": "Andrii",
    "email": "user@example.com"
  }
}
```

---

###  Отримання списку курсів

**GET /api/courses**

**Response:**

```json
[
  {
    "id": "course_id",
    "title": "Основи JavaScript",
    "description": "Курс для вивчення базових понять JavaScript"
  }
]
```

---

###  Надсилання коду на перевірку

**POST /api/check-code**

```json
{
  "language_id": 63,
  "source_code": "console.log('Hello World');",
  "stdin": ""
}
```

**Response:**

```json
{
  "status": "Accepted",
  "output": "Hello World",
  "error": null
}
```

---

###  Збереження прогресу користувача

**POST /api/progress**

```json
{
  "userId": "user_id",
  "courseId": "course_id",
  "completedTasks": 5,
  "testResult": 80
}
```

**Response:**

```json
{
  "message": "Прогрес користувача збережено"
}
```

##  Інструкція для користувача

1. **Головна сторінка**

   * користувач може переглянути загальну інформацію про платформу;
   * доступні кнопки входу та реєстрації.

2. **Реєстрація**

   * користувач вводить ім’я, електронну пошту та пароль;
   * після успішної реєстрації може авторизуватися в системі.

3. **Авторизація**

   * користувач вводить електронну пошту та пароль;
   * після входу отримує доступ до курсів і власного профілю.

4. **Проходження курсу**

   * користувач обирає доступний курс;
   * переглядає теоретичний матеріал;
   * переходить до практичних завдань.

5. **Виконання практичного завдання**

   * користувач пише програмний код у редакторі;
   * натискає кнопку перевірки;
   * система надсилає код на Judge0 API;
   * користувач отримує результат перевірки.

6. **Тестування**

   * після виконання практичних завдань користувач проходить тест;
   * результат тестування зберігається у системі.

7. **Прогрес користувача**

   * система зберігає виконані завдання;
   * користувач може переглядати власний прогрес;
   * у профілі відображаються результати навчання.

8. **Система досягнень**

   * користувач отримує досягнення за виконання завдань;
   * досягнення допомагають підвищити мотивацію до навчання.

##  Проблеми і рішення

| Проблема                       | Можлива причина                      | Рішення                                                      |
| ------------------------------ | ------------------------------------ | ------------------------------------------------------------ |
| Сервер не запускається         | Не встановлені залежності            | Виконати команду `npm install` у папці backend               |
| Помилка підключення до MongoDB | Неправильний `MONGO_URI`             | Перевірити посилання на базу даних у `.env`                  |
| Frontend не запускається       | Не встановлені залежності            | Виконати команду `npm install` у папці frontend              |
| Помилка CORS                   | Не налаштований CORS middleware      | Додати або перевірити налаштування `cors` у backend          |
| Код не перевіряється           | Неправильний ключ або URL Judge0 API | Перевірити `JUDGE0_API_KEY` та `JUDGE0_API_URL`              |
| Не зберігається прогрес        | Проблема з API або базою даних       | Перевірити маршрут `/api/progress` та підключення до MongoDB |
| Користувач не може увійти      | Неправильний email або пароль        | Перевірити введені дані або створити нового користувача      |
